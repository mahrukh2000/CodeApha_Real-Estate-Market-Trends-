# CodeApha_Real-Estate-Market-Trends
# Real Estate Market Trends Dashboard
# Project Overview
This project presents an interactive Real Estate Market Trends dashboard developed using Microsoft Power BI.

# Objectives
- Analyze property prices and rental yields
- Compare real estate market trends across cities
- Analyze market demand and supply conditions
- Evaluate economic indicators affecting the real estate market
- Identify potential investment opportunities
- Support investment and development decisions

# Dashboard Pages
## 1. Market Overview
- Average Property Price
- Average Rental Yield
- Average Price Per Sq Ft
- Average Days on Market
- Total Properties
- City-wise Property Price Analysis
- City-wise Rental Yield Analysis
- Property Price Trends Over Time
- Property Type Distribution

## 2. Demand, Supply & Economic Indicators
- Average Demand Index
- Average Supply Index
- Average GDP Growth
- Average Interest Rate
- City-wise Demand Analysis
- Market Condition Distribution
- GDP Growth vs Property Prices
- Interest Rate vs Property Prices

## 3. Investment Insights & Opportunities
- City-wise Investment Metrics
- Average Demand Index Comparison
- Average Property Price Comparison
- Average Rental Yield Comparison
- Property Price vs Rental Yield Analysis
- City-wise Investment Potential
- Interactive City Filtering
- Investment Decision Support

# Tools Used
- Microsoft Power BI
- Power Query
- DAX
